⏺ Based on the Claude Code documentation, here's how to add custom sub-agents:

  Adding Sub-Agents to Claude Code

  Quick Method: Interactive Command

  /agents
  This opens an interactive interface to create and manage sub-agents.

  Manual Method: Create Configuration Files

  1. Choose a location:
  - Project-level: .claude/agents/ (specific to this project)
  - User-level: ~/.claude/agents/ (available across all projects)

  2. Create a markdown file with this format:

  ---
  name: your-agent-name
  description: When to use this subagent (Claude uses this to decide when to invoke it)
  tools: Read, Write, Edit, Bash  # Optional: limit which tools the agent can use
  model: sonnet  # Optional: sonnet, opus, haiku, or 'inherit'
  ---

  Your detailed system prompt goes here.
  Define the agent's role, expertise, and behavior.

  Example: Create a Code Review Agent

  # Create the agents directory
  mkdir -p .claude/agents

  # Create a code reviewer agent
  cat > .claude/agents/code-reviewer.md << 'EOF'
  ---
  name: code-reviewer
  description: Use this agent to review code for quality, security, and best practices
  tools: Read, Grep, Bash
  model: sonnet
  ---

  You are a senior code reviewer with expertise in software engineering best practices.

  When reviewing code:
  1. Check for security vulnerabilities
  2. Verify adherence to coding standards
  3. Identify potential bugs or edge cases
  4. Suggest performance improvements
  5. Provide constructive, actionable feedback

  Focus on providing clear, specific recommendations with examples.
  EOF

  Key Configuration Parameters

  - name: Unique identifier (lowercase, hyphen-separated)
  - description: Critical! Claude reads this to decide when to invoke the agent automatically
  - tools: Optional comma-separated list. If omitted, inherits all tools
  - model: Optional. Choose sonnet, opus, haiku, or inherit

  Best Practices

  ✅ Do:
  - Keep agents focused on a single purpose
  - Write detailed, specific descriptions
  - Limit tool access to only what's needed
  - Use descriptive system prompts

  ❌ Don't:
  - Create overly broad agents
  - Give all agents access to all tools
  - Use vague descriptions

  Verify Your Agents

  After creating agents, Claude Code will automatically detect them. The description field determines when Claude proactively invokes each agent.
